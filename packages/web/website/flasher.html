Supported Devices

The Web Flasher supports the following hardware

BitAxe Series

Full support for BitAxe Ultra, Supra, and Gamma devices. Flash custom RetardioChain mining firmware for optimized CPU mining.

NerdMiner

Support for NerdMiner devices based on ESP32. Convert your lottery miner to mine RetardioChain.

Generic ESP32

Flash custom firmware to any ESP32 or ESP32-S3 based device. Build your own RetardioChain mining hardware.

How to Flash

Step-by-step instructions for flashing your device

1

Connect Your Device

Connect your ESP32 device to your computer using a USB cable. Make sure you have the appropriate drivers installed.

Windows Users 
If your device isn't recognized, install CP210x or CH340 drivers from the manufacturer's website.
2

Select Device Type

Choose your device from the dropdown menu. This ensures the correct firmware and partition scheme is used.

3

Click Connect

Click the "Connect Device" button and select your device from the browser's serial port picker. Grant permission when prompted.

Note: The Web Flasher requires a Chromium-based browser (Chrome, Edge, Brave) with Web Serial API support.

4

Flash Firmware

Click "Flash Firmware" to begin the flashing process. Do not disconnect your device during flashing. The process typically takes 1-2 minutes.

5

Configure Your Device

After flashing, your device will reboot and create a WiFi access point. Connect to it and configure your pool settings through the web interface.

Troubleshooting

Common issues and solutions

Device not detected
Install USB drivers (CP210x for most devices). Try a different USB cable - some cables are charge-only. Use a USB 2.0 port instead of USB 3.0.
Connection failed
Close any other applications using the serial port (Arduino IDE, PuTTY, etc). Try disconnecting and reconnecting the device.
Flash failed
Hold the BOOT button on your device while clicking "Flash Firmware". Some devices require this to enter bootloader mode.
Browser not supported
Use Chrome, Edge, or Brave browser. Firefox and Safari do not support the Web Serial API. Enable "Experimental Web Platform features" in chrome://flags if needed.
Device stuck in boot loop
Re-flash with the "Erase Flash" option enabled. This will clear all existing configuration and start fresh.
