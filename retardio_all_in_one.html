NerdMiner Setup:

2. Go to 192.168.4.1 in your browser
3. Enter pool: POOL_HOST_HERE:3333
4. Enter your wallet address as username
5. Password: x
6. Save and restart
BitAxe Setup:
1. Access BitAxe web interface
2. Go to Settings → Pool
3. Pool URL: stratum+tcp://POOL_HOST_HERE:3333
4. Worker: Your wallet address
5. Password: x
6. Save and apply
CPU Mining (Windows):
1. Download cpuminer from releases
2. Run this command:
cpuminer -a sha256d -o stratum+tcp://POOL_HOST_HERE:3333 -u YOUR_WALLET -p x
